# Synthetic Sample Data

All files in this directory are synthetic and intended for training, tests, and demonstrations. Do not store real or private evidence in this repository.

| File | Purpose |
| :--- | :--- |
| `auth.log` | Authentication failures followed by a successful login and privilege escalation indicators. |
| `nginx_access.log` | Web requests containing traversal and SQL injection patterns. |
| `windows_security.csv` | Windows logon failure and success events. |
| `clean_baseline.log` | Benign baseline expected to produce no rule matches. |
| `notes.txt` | Scenario notes and synthetic chain-of-custody context. |
| `small.pdf` | Valid sample PDF used for evidence preview and reporting demonstrations. |
